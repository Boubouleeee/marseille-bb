# OpenStreetMap source extract

`vieux-port.osm.gz` is a clipped OpenStreetMap XML extract for the Vieux-Port test zone, downloaded from the OpenStreetMap API. The source bbox is 5.366,43.2905,5.382,43.301 (WGS84). It contains real mapped roads and building footprints, not fictional commercial targets.

OpenStreetMap data is available under the Open Database License (ODbL). This extract and the generated map database are distributed under ODbL-1.0. Attribution: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright.

Regenerate the game map with `npm run map:generate`. Refresh the source extract from OpenStreetMap and regenerate it with `npm run map:update`.
